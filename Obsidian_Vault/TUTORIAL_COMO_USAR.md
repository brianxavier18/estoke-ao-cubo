# 📘 Tutorial: Como Importar o "Cérebro" para o Obsidian

Para que você tenha o sistema de ligações completo e visual, siga estes passos simples:

### 1. Abra o Obsidian
Se ainda não tem, baixe em [obsidian.md](https://obsidian.md).

### 2. Abrir como Vault (Cofre)
1. No Obsidian, clique no ícone de "Cofre" (Vault) no canto inferior esquerdo.
2. Selecione **"Open folder as vault"** (Abrir pasta como cofre).
3. Navegue até a pasta do seu projeto: 
   `g:\Meu Drive\100\EstokeAoCubo\Obsidian_Vault`
4. Clique em **"Select Folder"**.

### 3. Explore as Ligações
- O arquivo principal é o **[[EstokeAoCubo_MOC]]**. Clique nele para começar.
- Use `Ctrl + Clique` em qualquer texto azul para pular para aquela nota.
- **O PULO DO GATO:** Aperte `Ctrl + G` para abrir a **Graph View**. Você verá uma teia de aranha mostrando como todo o seu código está conectado!

### 4. Dicas de Ouro
- **Plugins Sugeridos**: Ative o plugin nativo "Backlinks" e "Graph View".
- **Temas**: O tema "Minimal" ou "AnuPpuccin" fica excelente com os callouts que eu configurei.
